Research

FoldPipe

Bounded remote streaming of native molecular shards with asynchronous prefetch.

Active

FoldPipe is a lightweight Python orchestration layer for remotely stored PyTorch and PyTorch Geometric molecular-data shards.

It keeps a bounded number of shard payloads live while retrieving the next shard concurrently with computation on the current shard.

The research evaluation uses a paired SchNet/MD17 benchmark to distinguish direct evidence of I/O–compute overlap from the more variable end-to-end runtime effect.
